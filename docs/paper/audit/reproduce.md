# Reproducing the Rev.1 results

This note maps each reported result to the command or artifact that produces it. It is
intended for the repository/Zenodo deposit and for reviewers who want to check a number.

## Environment

- Windows workstation; Python `.venv` in the repository root.
- Install: `pip install -r requirements.txt` (the repository's pinned environment).
- API keys are read from `.env` (names only): `SILICONFLOW_API_KEY`, `DEEPSEEK_API_KEY`,
  `XIAOMI_API_KEY`, `QWENAI_API_KEY`. No keys are stored in tracked files.
- Local models: `Qwen3-Embedding-0.6B` (embedding) and `mdeberta-v3-mnli-xnli` (NLI),
  loaded from `models/` or the Hugging Face cache.
- Frozen model set: `config/models.lock.yaml` and Table 6 of the manuscript.

## Data and index

```bash
python main.py --build-db          # PoultryDB vector index for the current species
```

- Corpus: `corpus/shared/*.csv`, `corpus/layer/*.csv`.
- Provenance: `corpus/provenance.csv`; per-breed table in Supplementary S3.
- Query set: `queries/layer/evaluation_queries_curated.json` (54 queries).

## E18 main comparison (7 methods x 54)

```bash
python main.py --compare --query-file queries/layer/evaluation_queries_curated.json
```

- Responses: `logs/comp_layer_<timestamp>/responses.json`.
- EvaluatorLLM scores: the run scores automatically; if `score_bulk` drops items,
  `python scripts/paper/rescore_comparison.py --log-dir <dir> --models NutriCHAT`
  re-scores with batch 5 and a per-item fallback.
- Expert sheets: `python scripts/export_for_expert_eval.py <dir>` then
  `python scripts/paper/build_blinded_expert_sheet.py <dir>`.
- Primary expert: 378 responses (`docs/paper/audit/expert_eval_all.csv`).
- Second expert: 120 responses (`docs/paper/audit/expert_eval_second_rater.csv`).
- Protocol: `docs/paper/audit/expert_scoring_protocol.md`.

## E1 architecture factorial

```bash
python main.py --ablation --ablation-dim architecture_factorial
```

- Six conditions: standalone, tools-only, tools+RAG, tools+RAG+synthesis,
  multi-agent validation off/on.
- Per-query re-score: `scripts/paper/rescore_variants.py` with the variant names.
- Output: `docs/paper/audit/e1_rescored.json`; Figure 11 and Table 7.

## E2 synthesis factorial

```bash
python main.py --ablation --ablation-dim synthesis_factorial
```

- Six conditions: concatenation, validation+concatenation, synthesis with validation
  off/shuffled/correct, query-only synthesis.
- Output: `docs/paper/audit/e2_rescored.json`; Table 7.

## D2-D6 re-runs

```bash
python main.py --ablation --ablation-dim specialist
python main.py --ablation --ablation-dim router
python main.py --ablation --ablation-dim rag
python main.py --ablation --ablation-dim llm_backbone
```

- Reports are copied to `docs/paper/audit/d2_specialist_report.*`,
  `d3_router_report.*`, `d4_rag_report.*`, `d6_backbone_report.*`.
- Some cells have n < 54 because EvaluatorLLM returned empty/malformed JSON; the
  manuscript labels these as provisional. Re-scoring uses
  `scripts/paper/rescore_variants.py --batch-size 3`.

## Audits (no LLM judge)

```bash
python scripts/paper/e3_validator_eval.py       # 42-pair validator test
python scripts/paper/e4_claim_aware.py          # claim-aware numeric audit
python scripts/paper/e5_selfcheck_n.py --limit 20
python scripts/paper/e6_retrieval_k.py          # hit@k / MRR
python scripts/paper/e9_repeatability.py        # 10 queries x 3 runs
python scripts/paper/e11_bilingual_auto.py      # Chinese vs English auto scores
python scripts/paper/e15_entity_resolution.py   # 39 perturbation cases
```

Outputs are in `docs/paper/audit/`; each script prints its aggregate and writes JSON+MD.

## Figures

```bash
python docs/paper/generate_figures.py
```

- Figure 11 reads the hard-coded Rev.1 contrasts in `fig11_ablation_bar()`; exact values
  and sample sizes are in Tables 4 and 7.
- Fig. 5 is generated by `docs/paper/generate_fig5_rev1.py`; Fig. 8/9/10 are generated by
  `docs/paper/generate_fig8_9_10_expert.py` from the primary expert scores. Fig. 6/7 remain
  submitted-run automated panels (readability/cost) and are labeled as such.
