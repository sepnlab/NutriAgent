# Expert Re-Scoring Protocol — Rev.1 (E18 / E12)

> **Status**: completed 2026-10-21. Primary 378 responses; one additional 120-response
> sheet is a same-expert repeat/copy pass (user-confirmed) and is reported as intra-rater
> consistency, not independent inter-rater. The independent third rater is used for the
> ICC/kappa/Bland–Altman check. See `expert_analysis.md`.
> **Scope**: 54 curated queries × 7 systems = 378 responses for the primary expert;
> a stratified subset (target 120, range 100–250) for the independent second rater.

## 1. Materials sent to each rater

1. `expert_eval_all.csv` — **one** sheet with all 378 responses (54 queries × 7
   systems), anonymized as `Model_A` … `Model_G`, shuffled within each query. The
   rater does not receive separate system/baseline files.
2. `ground_truth.json` — expected values and expected behaviours for the 54 queries.
3. `scoring_rubric.md` — the 1–5 rubric for correctness, precision, and scientific depth.
4. `query_set.md` — the curated query list with IDs and types.
5. This protocol.

The label map (`expert_eval_all_map.json`) is held by the corresponding author and is
**not** sent to the rater.

## 2. Blinding and randomization

- Model identities are replaced by `Model_A` … `Model_G`; the mapping is held by the
  corresponding author and is not sent to the rater.
- Within each query, responses are presented in a random order generated with seed 42.
- The rater scores one query group at a time and does not see other raters' scores.
- The rater is instructed not to search for the response text online or to discuss scores
  with the authors during scoring.

## 3. Rubric (summary)

| Score | Correctness | Precision (numeric; N/A for definitions) | Scientific depth |
|---|---|---|---|
| 5 | All facts accurate and directly answers the query | Exact point estimate matching the reference | Thorough mechanistic understanding with practical context |
| 4 | Mostly accurate, minor imprecision | Close estimate | Good domain knowledge |
| 3 | Partially correct, noticeable errors | Directionally correct but noticeably off | Adequate but surface-level |
| 2 | Several factual errors | Vague or significantly inaccurate | Superficial |
| 1 | Completely incorrect or irrelevant | No numeric answer when one is expected | No scientific content |

**Provenance (separate column, 0–2).** 0 = no source attribution; 1 = some key numbers
cite a tool/source; 2 = every key number is attributed to a named tool or source. This
column is scored independently of correctness and is not folded into the correctness
score. It is optional if the rater prefers not to score it; leave it blank in that case.

## 4. Primary expert (E18)

- 378 responses (54 queries × 7 systems), expected 2–3 working days.
- Single session with breaks; record start/end time and total hours.
- Return the two CSVs with the score columns filled; keep the `notes` column for
  query-specific comments (optional but useful for error analysis).
- The primary expert's scores replace the submitted expert scores in the main comparison;
  submitted scores are retained only for historical comparison and are not mixed.

## 5. Independent second rater (E12)

- Stratified random subset of 120 responses (seed 42): two responses per query
  (54 × 2 = 108) plus 12 sampled from the remainder, so all 54 queries are covered;
  model counts are 11–21 per anonymous label. Generated by
  `scripts/paper/sample_second_rater.py`; the exact IDs are in the manifest.
- Same rubric and blinding; independent session.
- Two 120-response sheets were returned. One is a same-expert repeat/copy pass from the
  primary (user-confirmed); it gives intra-rater ICC 0.995/0.996/0.932 and is not used as
  an independent inter-rater estimate. The independent third rater gives ICC(2,1) =
  0.847/0.876/0.760, weighted kappa 0.846/0.874/0.758, and Bland–Altman
  −0.27/−0.11/+0.21; see `expert_analysis.md`.
- Analysis: ICC(2,1), quadratic weighted kappa, Spearman ρ with bootstrap CI, Bland–Altman;
  `scripts/paper/agreement.py --second-rater <csv>`.
- If fewer than 100 responses are feasible, report the reduced n and treat the analysis as
  descriptive.

## 6. Conflicts of interest and independence

- Both raters are independent of the system development and have no financial relationship
  with the authors.
- Affiliations and roles are disclosed in the Acknowledgments (anonymized in the main text
  during review).
- The corresponding author does not score any response.

## 7. What the manuscript will report

- Primary expert scores for all 378 responses (Table 5) with paired bootstrap CIs and

- Second-expert subset: n, ICC(2,1), weighted κ, Spearman ρ, and Bland–Altman limits of
  agreement (Supplementary S5).
- Raw anonymous scores, the randomization seed, and the sampling script in the repository.
